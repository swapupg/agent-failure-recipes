# Code of conduct

Be respectful, specific and constructive. Welcome beginners. Critique code and ideas rather than people. Harassment, discriminatory language, threats, doxxing, spam and sharing confidential information are not acceptable.

Maintainers may edit or remove harmful content and restrict participation for repeated or severe violations. Report concerns through GitHub's reporting controls or a private repository security report when sensitive details are involved. Do not publish someone else's personal information in a report.
