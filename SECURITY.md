# Security

Report vulnerabilities through this repository's GitHub **Security → Report a vulnerability** form. Please do not post exploit details or secrets in a public issue. Support is best effort; no response-time promise is made.

The demo executes only bundled fixtures. It accepts no uploaded code or traces, runs no model API calls and stores only an optional theme preference. Hosting requests are processed by GitHub Pages. Downloaded evidence contains the bundled synthetic data, not a visitor's system.

These examples are educational. They do not implement production persistence, authentication, tenant isolation or a secure agent sandbox. Use disposable resources when adapting them. Pin package versions and inspect dependencies. Never grant an untrusted pull request deployment credentials.
