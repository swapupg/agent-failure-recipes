A SMALLER STARTING POINT

Keep your stack.
Add an assertion.

These recipes teach what to check when the software around an agent fails. They fit alongside your existing tests.

Does a passing recipe prove my agent is safe?

No. It proves one invariant under one controlled fault. Your integrations, permissions, persistence, concurrency and model behavior need their own tests.

Why is the broken test suite green?

The teaching tests assert that the bug is reproduced. For an intentionally failing command, run a recipe with --variant broken. It exits with code 1.

What information leaves my browser?

The lab makes no model or tool API calls and sends no analytics. Theme preference is saved locally when available. GitHub Pages serves the files and may keep hosting logs. Links to external sources navigate to those sites.
